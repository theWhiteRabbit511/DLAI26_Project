# DLAI26_Project
With this project, we started from the work "Conditional Neural Cellular Automata for Class-Specific Morphogenesis of Handwritten Digits" (arXiv:2512.08360), in which the authors tried to build a c-NCA capable of replicating different MNIST digits based on the morphogenetic signal the grid receives. The work itself has some problems, which we fixed using standard techniques from the field of NCA (Growing Neural Cellular Automata, Mordvintsev et al., 2020), and then we proposed another c-NCA model which performed much better.
