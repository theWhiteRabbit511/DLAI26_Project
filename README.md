# DLAI26_Project
This repository is based on the work: Conditional Neural Cellular Automata (c-NCA), the architecture proposed by Sakour et al. ("Conditional Neural Cellular Automata for Class-Specific Morphogenesis of Handwritten Digits", arXiv:2512.08360), which itself builds on Growing Neural Cellular Automata (Mordvintsev et al., 2020). We extend this work and provinding some adjustment.
